# 🐍 تعلم بايثون ببساطة

مشروع موقع تعليمي بسيط يهدف إلى شرح أساسيات لغة **Python** باللغة
العربية بطريقة سهلة ومنظمة، مناسب للمبتدئين.

------------------------------------------------------------------------

## 📌 فكرة المشروع

الموقع عبارة عن صفحة ويب تحتوي على:

-   شرح مبسط لأساسيات لغة بايثون\
-   تصميم تفاعلي وسهل الاستخدام\
-   قائمة جانبية للتنقل بين الدروس\
-   أكواد تطبيقية لكل درس

------------------------------------------------------------------------

## 🎯 محتويات الموقع

### 1. مقدمة عن بايثون

-   تعريف لغة بايثون
-   مثال بسيط للطباعة

### 2. المتغيرات (Variables)

-   تعريف المتغير
-   أمثلة على تخزين البيانات

### 3. أنواع البيانات (Data Types)

-   Integer\
-   Float\
-   String

### 4. الحلقات (Loops)

-   استخدام `for loop`
-   تكرار الأوامر

### 5. الدوال (Functions)

-   تعريف الدوال
-   مثال عملي
